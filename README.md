# Installation instructions:
To install this applciation you must clone the repository then cd into the repo and run: 
```
npm install
```
this will install the needed requirements. From there the best way to use the program is to run:
```
npx vite
```
in the home directory of the repository then navigate to the given url. If this doesnt work or it gives you a prompt asking you to update your npm then use [Node Version Manager](https://github.com/nvm-sh/nvm) to update it to the lts version then try again.
